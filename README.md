# Cosmic Curiosity

> Discover a random glimpse of the universe using NASA's Astronomy Picture of the Day API.

Cosmic Curiosity is a simple web application that fetches a random **NASA Astronomy Picture of the Day (APOD)** and displays the astronomy image or video along with a short explanation.

## ✨ Features

- 🚀 Discover a random astronomy entry
- 🌌 Uses NASA's APOD API
- 🖼️ Supports astronomy images
- 📺 Supports video entries
- 📅 Randomly selects a date from NASA APOD's archive
- 📱 Responsive design
- 🎥 Space-themed background video

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- NASA APOD API

## ⚙️ How It Works

1. Click the **🚀 Discover** button.
2. The application generates a random date.
3. The date is sent to NASA's APOD API.
4. The returned astronomy content is displayed.
5. Depending on the media type, the application displays an image or provides a link to the video.
